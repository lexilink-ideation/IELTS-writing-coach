B2 Task 2

Unit 7: Problem-Solution Essay (Full)

Skill focus: Task 2 — Problem-Solution Structure (Full)

1 Mini Lesson

A full problem-solution paragraph offers two solutions instead of one, each linked to its own result. This shows the examiner you can develop an idea fully rather than stopping after a single suggestion.

One major problem is ___ (problem). One effective solution would be to ___ (solution 1); this would help because ___ (result 1). Another solution would be to ___ (solution 2), which would ___ (result 2).

Two linked solutions, each with its own result, make your response noticeably more developed than a single problem-solution sentence.

2 Model Sentences

This example uses a different topic (job losses from automation) so you can see the pattern — then apply it to the new topic below.

  • One major problem is that automation is replacing workers in manufacturing and retail jobs at a rapid pace. One effective solution would be to expand government-funded retraining programmes; this would help because it allows displaced workers to move into growing industries such as healthcare or technology. Another solution would be to introduce a shorter working week across affected sectors, which would spread the remaining work more evenly among employees.

3 Guided Practice

Fill in the gaps using the topic below (not the model paragraph above):

One major problem is ___ (traffic congestion in cities). One effective solution would be to ___ (solution 1); this would help because ___. Another solution would be to ___ (solution 2), which would ___.

5 Self-Review Checklist

  • I stated the problem clearly using a phrase like "one major problem is".
  • I proposed a first solution using "one effective solution would be to".
  • I linked my first solution to a result with a cause-effect phrase.
  • I proposed a second solution using "another solution would be to".
  • My paragraph is about traffic or congestion in cities.
  • I wrote at least 55 words.
