A1 Task 1

Unit 6: Describing Three Data Points

Skill focus: Task 1 — Multiple Data Description

1 Mini Lesson

Sometimes a table has more than one row. You can describe each row with its own simple sentence — just repeat the pattern you already know for every number.

___ (number) students preferred ___ (category).

Write one short sentence for each row, in the same order as the table.

2 Model Sentences

These examples use a different topic (transport to school) so you can see the pattern — then apply it to the new data below.

  • 30 students preferred the bus.
  • 45 students preferred walking.
  • 10 students preferred the car.

3 Guided Practice

Fill in the gaps using the data in the table below (not the model sentences above):

___ (number) students preferred books. ___ (number) students preferred videos. ___ (number) students preferred both.

Now write all three sentences yourself in the writing box below.

5 Self-Review Checklist

  • My first sentence starts with a capital letter.
  • Every sentence ends with a full stop.
  • I included all three numbers: 25, 60, and 15.
  • I mentioned "books" and "videos".
  • I wrote one sentence for each row of the table.
