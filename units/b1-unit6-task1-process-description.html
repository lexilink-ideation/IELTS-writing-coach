B1 Task 1

Unit 6: Describing a Simple Process

Skill focus: Task 1 — Process Description

1 Mini Lesson

When a diagram shows a short process, describe each step in order. Use "first", "next", and "finally" to make the sequence completely clear to the reader.

First, ___ (step 1). Next, ___ (step 2). Finally, ___ (step 3).

"First", "next", and "finally" act like signposts — the reader always knows exactly where they are in the process.

2 Model Sentences

This example uses a different topic (buying a train ticket) so you can see the pattern — then apply it to the new process below.

  • First, the passenger selects their destination on the ticket machine. Next, they insert a payment card to complete the purchase. Finally, they scan the ticket at the gate before boarding the train.

3 Guided Practice

Fill in the gaps using the steps in the table below (not the model sentence above):

First, the student ___ (step 1). Next, the student ___ (step 2). Finally, the student ___ (step 3).

Now write your full description yourself in the writing box below.

4 Writing Box

Prompt: The table below shows the steps a student follows to sign up for an online class. Describe the process in order.

Steps: Signing Up for an Online Class

StepWhat Happens
1. Create AccountStudent registers with a name, email, and password
2. Choose a CourseStudent browses the course list and selects one to join
3. Confirm EnrollmentStudent receives a confirmation email and gains access to the course

Look at the steps. Now describe the whole process in order using "first", "next", and "finally" — don't copy the lesson example.

5 Self-Review Checklist

  • I used "next" for the second step.

  • My description is about signing up for an online class.
