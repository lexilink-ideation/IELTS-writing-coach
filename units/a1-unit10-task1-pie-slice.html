A1 Task 1

Unit 10: One Slice of a Pie Chart

Skill focus: Task 1 — Pie Chart Basics

1 Mini Lesson

A pie chart is a circle cut into slices. You can describe one slice with one simple sentence. Use "accounts for" to show what percentage a category takes up.

___ (category) accounts for ___% (number).

"Accounts for" is the first piece of pie-chart vocabulary — later you will learn more words like "comprises of" and "represents".

2 Model Sentences

This example uses a different topic (public transport) so you can see the pattern — then apply it to the new data below.

  • Buses accounts for 40% of journeys to work.

3 Guided Practice

Fill in the gap using the data in the pie chart below (not the model sentence above):

___ (activity) accounts for ___% of children's screen time.
