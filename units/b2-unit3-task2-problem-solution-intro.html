B2 Task 2

Unit 3: Problem-Solution Essay Intro

Skill focus: Task 2 — Problem-Solution Structure

1 Mini Lesson

Problem-solution questions ask you to state a problem clearly, then propose one clear, workable solution, and finally link the two with a cause-effect phrase.

One major problem is ___ (problem). One effective solution would be to ___ (solution). This would help because ___ (result).

Keep the problem and the solution in separate sentences — don't blend them into one confusing sentence.

2 Model Sentences

This example uses a different topic (traffic congestion) so you can see the pattern — then apply it to the new topic below.

  • One major problem is that traffic congestion in cities has increased significantly due to the rising number of private cars. One effective solution would be to invest more heavily in public transport networks. This would help because it gives commuters an affordable and convenient alternative to driving.

3 Guided Practice

Fill in the gaps using the topic below (not the model paragraph above):

One major problem is ___ (a pollution issue). One effective solution would be to ___ (solution). This would help because ___ (result).

5 Self-Review Checklist

  • I stated the problem clearly using a phrase like "one major problem is".
  • I proposed one clear solution using a phrase like "one effective solution would be to".
  • I linked the problem and solution with a cause-effect phrase (e.g. "this would help because").
  • My paragraph is about pollution or the environment.
  • I wrote at least 40 words.
