A1 Task 2

Unit 7: Two-Sentence Opinion Paragraph

Skill focus: Task 2 — Paragraph Building (Intro)

1 Mini Lesson

So far you have written one sentence at a time. Now you will write two sentences that work together: an opinion sentence, then a second sentence that supports it with "Because" or joins it with "and".

I think ___ (opinion). Because ___ (reason).

Two short, correct sentences are better than one long, confusing one.

2 Model Sentences

These examples use a different topic (online classes) so you can see the pattern — then apply it to the new topic below.

  • I think online classes are useful. Because students can learn from home.
  • I believe online classes save money. And students do not need to travel to school.

3 Guided Practice

Fill in the gaps using the topic below (not the model sentences above):

___ (I think / I believe) studying abroad is / is not a good idea. Because ___ (reason).

Now write both sentences yourself in the writing box below.

4 Writing Box

Prompt: Do you think studying abroad is a good idea?

5 Self-Review Checklist

  • My first sentence starts with a capital letter.
  • Every sentence ends with a full stop.
  • I used "I think" / "I believe".
  • I used "Because" or "And" to add a second sentence.
  • My paragraph is about studying abroad.
  • I wrote two sentences, not just one.
