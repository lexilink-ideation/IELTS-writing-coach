Unit 4: Full Academic Report Structure

Skill focus: Task 1 — Complete Report Structure

1 Mini Lesson

A complete Band 8-9 Task 1 report combines three things into one flowing piece: an overview sentence naming the single biggest overall pattern, body sentences that describe each category with precise figures, and an explicit comparison connecting the categories together — closed with a synthesis statement.

Overall, ___ (single biggest overview pattern). Concern about ___ (category 1) ___ (change language), while concern about ___ (category 2) ___ (change language). By contrast, ___ (category 3) ___ (change language). Taken together, ___ (comparison/synthesis statement).

Without the synthesis statement at the end, a report can read as a list of disconnected facts rather than one coherent piece of analysis.

2 Model Sentences

This example uses a different topic (attitudes toward remote work) so you can see the pattern — then apply it to the new data below.

  • Overall, attitudes toward remote work shifted dramatically among surveyed employees between 2019 and 2023. Support for full-time remote work rose sharply, climbing from a modest 18% to a striking 62%, while enthusiasm for hybrid arrangements grew only marginally, edging up from 40% to 45%. By contrast, preference for fully in-person work collapsed, plummeting from 42% down to just 12%. Taken together, the data suggests a decisive and sustained move away from traditional in-office work over the four-year period.
