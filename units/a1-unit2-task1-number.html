A1 Task 1

Unit 2: Describing One Number

Skill focus: Task 1 — Data Description

1 Mini Lesson

IELTS Task 1 asks you to describe data — charts, tables, and graphs. The first skill is describing one number clearly and accurately.

Useful patterns for describing data:

The number of...  |  There were...  |  In [year],...

Always include the year, the number, and what is being counted.

2 Model Sentences

These examples use a different topic (public transport) so you can see the pattern — then apply it to the new data below.

  • In 2023, 55 people liked public transport.
  • There were 55 people who liked public transport in 2023.
  • The number of people who liked public transport was 55 in 2023.
