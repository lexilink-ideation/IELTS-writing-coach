A2 Task 1

Unit 6: Describing Change Across a Table

Skill focus: Task 1 — Change Description

1 Mini Lesson

Not every row in a table changes the same way. Use "increased", "decreased", and "stayed the same" together so each row gets the correct word.

___ (item) increased from ___ to ___. ___ (item) decreased from ___ to ___. ___ (item) stayed the same at ___.

Using all three words shows you can match the right verb to what actually happened in each row, not just repeat one pattern.

2 Model Sentences

This example uses a different topic (daily exercise habits) so you can see the pattern — then apply it to the new data below.

  • The number of students who exercise daily increased from 20 to 35. The number who exercise rarely decreased from 40 to 25. The number who never exercise stayed the same at 15.

3 Guided Practice

Fill in the gaps using the data in the table below (not the model sentence above):

The percentage who recycle regularly increased from ___ to ___. The percentage who buy bottled water decreased from ___ to ___. The percentage who compost food waste stayed the same at ___.

Now write your full description yourself in the writing box below.

5 Self-Review Checklist

  • My first sentence starts with a capital letter.
  • Every sentence ends with a full stop.
  • I used "increased" for one habit.
  • I used "decreased" for another habit.
  • I used "stayed the same" for the third habit.
  • I included the numbers 40, 65, 55, 30, and 20.
