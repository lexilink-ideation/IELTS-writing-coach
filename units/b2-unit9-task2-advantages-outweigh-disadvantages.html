B2 Task 2

Unit 9: Advantages Outweigh Disadvantages

Skill focus: Task 2 — Weighing Essay (Type 2)

1 Mini Lesson

Unlike the no-opinion Advantages & Disadvantages essay (Type 1), this essay type — Do Advantages Outweigh Disadvantages? (Type 2) — requires you to explicitly state which side outweighs the other, with a reason. A clear opinion is essential here.

One advantage of ___ is that ___. However, one disadvantage is that ___. In my view, the advantages outweigh the disadvantages because ___.

The word "outweigh" is the key signal — without it, your answer reads like the no-opinion Type 1 essay instead.

2 Model Sentences

This example uses a different topic (online classes) so you can see the pattern — then apply it to the new topic below.

  • One advantage of online classes is that students can learn flexibly from anywhere. However, one disadvantage is that some students feel isolated without face-to-face contact. In my view, the advantages outweigh the disadvantages because flexibility allows far more people to access education than would otherwise be possible.

3 Guided Practice

One advantage of AI tools for homework is that ___. However, one disadvantage is that ___. In my view, the advantages outweigh the disadvantages because ___.

5 Self-Review Checklist

  • I named one advantage using "one advantage is that".
  • I used "However" to move to the disadvantage.
  • I named one disadvantage using "one disadvantage is that".
  • I explicitly stated which side "outweighs" the other.
  • I gave a reason for my judgement using "because".
  • My paragraph is about AI and homework.
  • I wrote at least 50 words.
