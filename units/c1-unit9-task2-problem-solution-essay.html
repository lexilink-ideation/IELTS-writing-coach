Unit 9: Problem, Not Cause: A Different Essay Type

Skill focus: Task 2 — Problem-Solution Essay

1 Mini Lesson

A Problem-Solution essay asks what problems a trend causes, and what should be done about them. This is different from a Cause-Solution essay, which asks why the trend is happening in the first place. Students frequently confuse the two: in a Problem-Solution essay, you are not explaining causes — you are identifying consequences and proposing a fix for them.

A significant problem caused by ___ is that ___. This could be addressed by ___, which would likely ___.

Notice the essay never asks "why is this happening" — it only asks what goes wrong as a result, and how to fix it.

2 Model Sentences

This example uses a different topic (children and screen time) so you can see the pattern — then apply it to the new topic below.

  • A significant problem caused by excessive screen time in children is that it can disrupt healthy sleep patterns and reduce opportunities for physical activity. This could be addressed by schools setting clear guidelines for recommended daily screen limits, which would likely help parents reinforce healthier habits at home.

3 Guided Practice

Fill in the gaps using the topic below (not the model paragraph above):

A significant problem caused by automation in the workplace is that ___. This could be addressed by ___, which would likely ___.

Now write your full paragraph yourself in the writing box below.

4 Writing Box

Prompt: Automation (machines and AI) is replacing many jobs previously done by humans. What problems does this create, and what could be done to address them? Remember: focus on the problems it creates, not on why automation is happening.

5 Self-Review Checklist

  • I stated a problem (a consequence), not a cause, using "a significant problem is that".
  • I proposed a solution using "this could be addressed by".
  • I linked my solution to its likely result using "which would likely".
  • My paragraph is about automation and jobs.
  • I wrote at least 65 words.
