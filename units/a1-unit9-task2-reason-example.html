A1 Task 2

Unit 9: Opinion, Reason, and Example

Skill focus: Task 2 — Reason + Example Paragraph

1 Mini Lesson

You already know how to give an opinion with "because". Now add one more part: a short example that shows your reason is true. Use the phrase:

for example

Opinion + reason + example is three short sentences that work together — this is the building block of a full IELTS paragraph.

2 Model Sentences

These examples use a different topic (public transport) so you can see the pattern — then apply it to the new topic below.

  • I think public transport is good. Because it reduces traffic. For example, one bus can carry forty people to work.
  • I believe public transport is cheap. Because tickets cost less than fuel. For example, a bus ticket can cost only two dollars.

3 Guided Practice

Fill in the gaps using the topic below (not the model sentences above):

___ (I think / I believe) children should / should not use tablets at school. Because ___ (reason). For example, ___ (example).

Now write all three sentences yourself in the writing box below.

4 Writing Box

Prompt: Do you think children should use tablets to learn at school?

5 Self-Review Checklist

  • My first sentence starts with a capital letter.
  • Every sentence ends with a full stop.
  • I used "I think" / "I believe" for my opinion.
  • I used "Because" to give a reason.
  • I used "For example" to give a real example.
  • My paragraph is about tablets or screens at school.
