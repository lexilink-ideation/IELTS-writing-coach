A1 Task 1

Unit 4: Describing a Simple Trend

Skill focus: Task 1 — Trend Description

1 Mini Lesson

IELTS Task 1 data can move in three simple directions. Learn these three basic phrases:

went up  |  went down  |  stayed the same

Pick the phrase that matches the data, then add "from ___ to ___" to show the starting and ending numbers.

2 Model Sentences

These examples use a different topic (students studying abroad) so you can see the pattern — then apply it to the new data below.

  • The number of students studying abroad went up from 20 to 45.
  • The number went down from 45 to 20.
  • The number stayed the same at 30 for both years.

3 Guided Practice

Fill in the gaps using the data in the table below (not the model sentences above):

The number of passengers ___ (went up / went down / stayed the same) from ___ to ___.

5 Self-Review Checklist

  • My sentence starts with a capital letter.
  • My sentence ends with a full stop.
  • I included both numbers, 90 and 50.
  • I used a trend word (went down / decreased / fell).
