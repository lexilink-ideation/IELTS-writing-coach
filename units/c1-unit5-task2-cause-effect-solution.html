C1 Task 2

Unit 5: Extended Cause-Effect-Solution Essay

Skill focus: Task 2 — Extended Cause-Effect-Solution

1 Mini Lesson

At C1 level, the strongest essays weave cause, effect, and solution into one flowing paragraph rather than treating them as separate, disconnected boxes.

___ (cause). This has led to ___ (effect). One way to address this would be to ___ (solution), which would ___ (result of the solution).

Connecting all three elements in sequence shows the examiner you can reason through a complex issue, not just list facts.

2 Model Sentences

This example uses a different topic (work and automation) so you can see the pattern — then apply it to the new topic below.

  • The rapid adoption of automation in manufacturing has significantly reduced the demand for low-skilled factory labour. This has led to rising unemployment in regions historically dependent on manufacturing industries, often triggering broader economic decline. One way to address this would be to invest heavily in retraining programmes that equip displaced workers with skills suited to emerging industries, which would help stabilise local economies while easing the transition into new forms of employment.

3 Guided Practice

Fill in the gaps using the topic below (not the model paragraph above):

___ (why young people move from rural areas to cities). This has led to ___ (effect on rural communities). One way to address this would be to ___ (solution), which would ___ (result).
