Unit 2: Chart Overview Sentence

Skill focus: Task 1 — Overview Writing

1 Mini Lesson

Every strong Task 1 report starts with an overview: one sentence that names the single biggest trend in the data, without listing every number. A supporting detail sentence can then point to the most striking part of that trend.

Overall, ___ (the general trend) between ___ (first year) and ___ (last year). In particular, ___ (one striking detail).

Save the smaller numbers for later sentences — the overview is about the big picture only.

2 Model Sentences

This example uses a different topic (public transport) so you can see the pattern — then apply it to the new data below.

  • Overall, the percentage of commuters using public transport rose considerably between 2017 and 2023. In particular, the sharpest increase occurred after 2019.

5 Self-Review Checklist

  • My first sentence starts with a capital letter.
  • Every sentence ends with a full stop.
  • I used an overview signal phrase such as "overall".
  • I used a trend word (increased / rose / grew).
  • I included both years, 2018 and 2023.
  • I added one supporting detail sentence.
